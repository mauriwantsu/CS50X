# CS50x: Introduction to Computer Science — Portfolio

Welcome to my portfolio for **CS50x: Introduction to Computer Science**, Harvard University's introductory course on computer science and the art of programming. 

This repository contains my weekly problem sets, lab assignments, and my final project. Throughout the course, I explored core concepts including algorithms, data structures, memory management, software engineering, and web development using C, Python, SQL, HTML, CSS, and JavaScript.

## Featured Project: Ashford 🎮

**Ashford** is my capstone final project for CS50x. It is an original interactive game built from scratch to apply and showcase the programming principles developed throughout the course.

### Overview & Key Features
* **Custom Game Logic:** Implements Object-Oriented Programming (OOP) principles to handle game states, player interactions, and core mechanics.
* **Modular Codebase:** Organized into clean, maintainable modules separating visual rendering, logic, and user input.
